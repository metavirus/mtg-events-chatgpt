## Store-by-store reassessment

### Finch and Sparrow Games

Event write recommendation:

- No new event write.
- Birdcage VII is already represented as a dated cEDH special event.
- Routine Finch Commander lanes are already represented separately from the
  Birdcage / Fish Bowl / cEDH special-event layer.

Assessment change recommendation:

- Add a dedicated evaluation row so the Places page can display positives,
  cautions, open questions, fit grade, score, and confidence.
- Do not rewrite the existing rich venue assessment as part of this tidy-up
  pass.

Fit grade / score / confidence direction:

- Recommended fit: B.
- Recommended score: 3.8 / 5.
- Recommended confidence: medium.
- Reasoning: Finch is close, WPN Premium, has multiple Commander lanes, and has
  user field notes. It is not scored higher because the best personal lane still
  depends on choosing the right night and avoiding conflation with the louder
  cEDH/special-event layer.

Positives:

- Only about 5 miles from Los Alamitos.
- WPN Premium store with meaningful MTG activity.
- Multiple Commander lanes: routine Thursday Commander, structured Saturday
  Commanderfest, Sunday casual/open-play signals, and separate cEDH specials.
- User field notes indicate Saturday had random pod assignment and Sunday had a
  more freeform casual vibe.
- Strong source routing across official site, Wizards/EventLink, Instagram, and
  prior direct user observation.

Cautions:

- Birdcage / Fish Bowl / cEDH specials are important store-character signals but
  are not casual Commander fit signals.
- Saturday structure and loose timed rounds may or may not be the user's best
  fit.
- Sunday casual/open-play appears promising but is not yet normalized as a clean
  recurring event record.
- Discord / pre-arrival coordination remains thinner than the ideal home-pod
  pathway.

Open questions:

- What is the current average Thursday Commander table like?
- What is the strongest current source route for Sunday open-play Commander?
- Is Sunday open play stable enough to model as its own recurring series?
- Which Finch lane is most useful for casual Bracket 2/3 repeat attendance?

Source/provenance updates:

- Event candidate replay A already refreshed Finch/Birdcage source provenance.
- No additional source rows are needed for this assessment proposal.

Does this change how the user should think about trying the place?

- Yes, but as refinement rather than a reversal. Finch remains a serious nearby
  candidate, but the user should think in terms of choosing the right lane:
  routine casual Commander or Sunday open play, not the cEDH/special-event
  layer.
