## Disposition

Current best classification:

**Still unresolved / branch-identity TBD.**

More specifically:

- Do **not** treat `JJ's Orange` as the same as JJ's Garden Grove.
- Do **not** attach Orange Discord schedule rows to `jjs-collectibles`.
- Do **not** create canonical Garden Grove events from Orange schedule text.
- Do **not** create a confident `JJ's Collectibles — Orange` Place yet.
- Preserve Orange as a branch/entity-resolution lead.

The strongest hypothesis is:

> The Discord `Orange` schedule may refer to a separate Orange card-shop surface
> possibly related to Hidden Collectibles 2 / `jjscardemporium.com`, but the
> relationship to JJ's Collectibles is not proven by non-Discord sources found
> in this bounded pass.

## What would resolve the TBD

Resolve with one of:

1. Official JJ's/Hidden source text linking Garden Grove and Orange as branches.
2. A store-controlled website/social profile naming both locations.
3. A Wizards/EventLink or registration record for an Orange branch with matching
   naming and address.
4. A Discord/store-controlled post that clearly states the Orange location name
   and address, paired with a non-Discord corroborating source.

Until then, Orange schedule findings should remain:

- source lead;
- branch identity TBD;
- possible future Signal only if written as an identity-resolution prompt, not
  as a Garden Grove event;
- no canonical event rows.
