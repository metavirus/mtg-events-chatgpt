## Preflight

- [ ] Discord survey is read-only.
- [ ] Exact route/channel target selected from `discord_access_profiles` /
  `discord_channel_watchlist`.
- [ ] Access mode confirmed:
  - `manual_open_required`
  - `direct_navigation_verified`
  - `route_only_tbd`
  - `join_or_role_gate`
  - `blocked_unsafe_method`
- [ ] No Discord message composer is focused.
- [ ] No typing or pasting into Discord.
- [ ] No keyboard navigation inside Discord message views.
- [ ] No clicking post/react/reply/upload/join/role/settings/send controls.
- [ ] No browser improvisation if navigation fails.
- [ ] If manual mode: user manually opened exact channel/message or supplied a
  screenshot/paste.
- [ ] If direct-navigation mode: method was previously protocol-tested and does
  not synthesize page-body input.
